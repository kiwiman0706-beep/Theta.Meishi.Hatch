## この版の変更

- **Theta Meishi Hatch 1.0**：Theta Hatch シリーズの名前・アプリ ID（`app.thetahatch.meishi`）にそろえた最初の版です。前の版（`jp.yaegaki.meishiclaude`）とは別のアプリとして入ります。
  - **移行は Theta Home Hatch から**：Home が、前の版を橋渡し版 0.19.0 に更新 → データを書き出し → この版を入れて読み込み → 前の版を削除、の順に進めます。名刺・画像・メモ・手書き・録音・Google 連絡先とのつながり・設定がそのまま移ります（Gemini の APIキー、Google の許可は入れ直し）。
  - **更新は Theta Home Hatch に任せます**：このアプリは自分ではインストールしません。新しい版の帯の「更新する」で Home が更新します（Home が無ければダウンロードページを開きます）。
  - **シリーズの設定**：Home に Gemini の APIキーやモデル、Google アカウントを入れておくと、この版で受け取れます（「Gemini APIキー・モデル」の「Theta Home Hatch の設定を使う」）。
- Windows/Mac：アプリの ID が変わるため、Windows では前の版と並んで入ります。前の版は「アプリと機能」から削除してください。
- Web 版のアドレスが https://kiwiman0706-beep.github.io/Theta.Meishi.Hatch/ に変わりました（ホーム画面への追加はやり直し。データは Google ドライブから戻ります）。
