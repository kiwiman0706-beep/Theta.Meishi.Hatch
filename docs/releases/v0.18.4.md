## この版の変更

- **新しい名刺の読み取りを最優先に**：「過去の名刺を最新の状態にする」（読み仮名・ロゴ）の残りが先に処理され、Geminiの1日の無料枠を使い切って新しい名刺が読めないことがありました。読み取りを先に行い、過去の名刺の更新は1日30回までに抑えて少しずつ進めます。メニューの「過去の名刺を更新中」から中止もできます。
- **Geminiの使用状況**：「Gemini APIキー・モデル」に、今日のこの端末からの呼び出し回数（用途別・断られた回数）と、Google AI Studio の使用状況・APIキー一覧・Google Cloud の割り当てへのリンクを追加しました。読み取りが止まったときのお知らせにも回数と「使用状況」ボタンを出します。
- 0.18.3 の、止まったときの理由と「再開」もご覧ください。
